== Wildcard and mixed content

The classes of `b7fdbe`, `b2e7ae`, `b80e2e` and `b0fd0e` hold wildcard or mixed content (`@XmlAnyElement`,
`@XmlMixed`) in a `List<Object> content`. Those of `b3da3e`, `b4347e`, `b9c1be`, `b95f5e` and `b872ce` do not.

An element of such content which no class of the context binds is read as a DOM `Element`, which has no value
`equals`. In the data:

[cols="3,5",options="header"]
|===
| Column | DOM elements

| `Production.ProductModel.CatalogDescription`
| In every row (6): the `OtherFeatures` elements of `Features` (`wheel`, `saddle`, `pedal`, `crankset`, `handlebar`,
`BikeFrame`, of `http://www.adventure-works.com/schemas/OtherFeatures`, which has no schema), the unqualified elements
of `Specifications` (`Color`, `Material`, `Style`, ...), and the XHTML `p` of `Summary`. `Warranty` and `Maintenance`
of `Features` bind to `b4347e` when the context knows it.

| `Person.Person.AdditionalContactInfo`
| None, when the context knows `b7fdbe`, `b80e2e` and `b2e7ae`: every row (10) binds to `ContactRecord` and the
`ContactTypes` classes.
|===

== equals and hashCode

[cols="2,5",options="header"]
|===
| Item | Status

| `equals` and `hashCode` of the binding's classes
| Generated since 0.0.4, which this project uses: `-Xequals -XhashCode` of `jaxb-plugins`, with a runtime dependency on
`jaxb-plugins-runtime` (4.0.16), and with a strategy comparing DOM elements by `isEqualNode` in `b7fdbe`, `b80e2e`,
`b2e7ae` and `b0fd0e`. Up to 0.0.3 no class overrode either, so Hibernate ORM found every loaded value of a writable
column changed.

| This module, once the binding has them
| Move to the binding's new version, and pin `jaxb-plugins-runtime` if dependency convergence asks for it; map the five
writable columns, `Resume`, `Person.Person.AdditionalContactInfo`, `Person.Person.Demographics`, `CatalogDescription`
and `Sales.Store.Demographics`, each with a converter, and test under both providers that every value converts and that
a flush of loaded rows writes nothing.
|===
