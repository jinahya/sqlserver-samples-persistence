Every column type the tables of AdventureWorks, WideWorldImporters and FutonManufacturing declare, grouped by the
categories of link:{data-types}[Data types (Transact-SQL)]. Each type is listed as the database's catalog
(`sys.columns`, `sys.types`) reports it, an alias type with the system type it is based on, and each column as
`Schema.Table.Column`; 1358 columns of 151 tables in all (486 of 71 in AdventureWorks, 557 of 48 in
WideWorldImporters, 315 of 32 in FutonManufacturing). WideWorldImporters' 17 `*_Archive` history tables repeat
the columns of the tables whose history they keep. The views are left out; see <<views>>.

The Java type is the type of the attribute which maps the column in the `Mapped*` classes, the wrapper types,
never a primitive, and `java.time` for the date and time types. A column whose type is not the usual one for its
declared type is named in the section's notes.

No column is `float`, `real`, `char`, `text`, `ntext`, `binary`, `image`, `smalldatetime`, `datetimeoffset`,
`rowversion`, `sql_variant`, `geometry`, `json` or `vector`.

== Exact numerics

See link:{data-types}#exact-numerics[Exact numerics].

`int`, `smallint` and `tinyint` are `Integer`s, and `bigint` a `Long`. An AdventureWorks `dbo` or
`HumanResources` table keyed by a single `IDENTITY` column extends `-common`'s `MappedWithIdentityId`, whose
`Long id_` maps the column whatever its width: `dbo.AWBuildVersion.SystemInformationID` and
`HumanResources.Shift.ShiftID` (`tinyint`), `HumanResources.Department.DepartmentID` (`smallint`), and
`dbo.DatabaseLog.DatabaseLogID`, `dbo.ErrorLog.ErrorLogID` and `HumanResources.JobCandidate.JobCandidateID`
(`int`). `Production.Location.LocationID` and `Production.ScrapReason.ScrapReasonID`, `smallint` `IDENTITY`
keys too, are `Long`s of their own. A foreign key to any of these keys is a `Long` as the key is, whatever it
declares, so that the two compare.

`decimal`, `numeric`, `money` and `smallmoney` are `BigDecimal`s. `Sales.SalesOrderDetail.LineTotal`, the one
`numeric`, is a computed column.
