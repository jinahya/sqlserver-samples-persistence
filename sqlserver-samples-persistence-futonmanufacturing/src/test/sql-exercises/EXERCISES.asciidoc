= Exercises
:toc: left
:toclevels: 3
:sectanchors:
:source-highlighter: rouge

Exercises for the FutonManufacturing database: questions a production planner, a buyer or a sales manager of a futon
maker would ask, each answered with a query. Every problem is stated as a request, followed by its answer. The `sql`
blocks are Transact-SQL against the installed database (see link:../../../../README.md[README.md]), with the values written
in; the files are in `src/test/sql-exercises/_dbo`, a file per level, each exercise under a ruler that carries its id.
The `jpaql` blocks are Jakarta Persistence 3.2 query language against this module's entities, with named
parameters. Each exercise has a class of its own in `src/test/java-exercises`, `futon.dbo.<ID>_PersistenceIT`; a picked
one answers it with the query language and with the Criteria API, or with a native query where the query language
cannot, and checks the rows the SQL gives.

An id is `FUTON_DBO_<TIER>_<NN>`, after `dbo`, the only schema; the tier is B (Basic), I (Intermediate) or A
(Advanced), and the number is within that tier. `EXERCISES.yaml` registers every id; an id is never reused or
renumbered.

The outputs were taken on 2026-11-01 from `sqlcmd -W -s '|'`, aligned with `column -t -s '|'`.

[[FUTON_DBO_B_01]]
=== FUTON_DBO_B_01: the direct components of a finished futon

The direct components of a finished futon, FG-FUT-003, with the quantity, the unit and the scrap rate of each.

[source,sql]
----
SELECT c.ItemCode, c.ItemName, b.Quantity, u.UnitCode, b.ScrapRate
FROM BillOfMaterials b
         JOIN Items p ON p.ItemID = b.ParentItemID
         JOIN Items c ON c.ItemID = b.ComponentItemID
         JOIN UnitOfMeasure u ON u.UnitID = b.UnitID
WHERE p.ItemCode = 'FG-FUT-003'
  AND b.IsActive = 1
ORDER BY c.ItemCode
;
----

[[FUTON_DBO_I_01]]
=== FUTON_DBO_I_01: the raw materials which four or more items use

The raw materials which four or more items use directly, with the number of those items, the most used first.

[source,sql]

WHERE t.TypeCode = 'RAW'
  AND b.IsActive = 1
GROUP BY c.ItemID, c.ItemCode, c.ItemName
HAVING COUNT(*) >= 4
ORDER BY Parents DESC, c.ItemCode
;

[[FUTON_DBO_I_02]]
=== FUTON_DBO_I_02: the material cost and the margin of each finished futon

Each finished futon's direct material cost, scrap included, and what remains of its list price; a futon without an active bill of materials shows NULL for both.

[source,sql]
----
SELECT p.ItemCode,
       p.ItemName,
       CAST(SUM(b.Quantity * (1 + b.ScrapRate / 100) * c.StandardCost) AS DECIMAL(18, 4))               AS MaterialCost,
       p.ListPrice,
       CAST(p.ListPrice - SUM(b.Quantity * (1 + b.ScrapRate / 100) * c.StandardCost) AS DECIMAL(18, 4)) AS Margin
FROM Items p
         JOIN ItemType t ON t.ItemTypeID = p.ItemTypeID
         LEFT JOIN BillOfMaterials b ON b.ParentItemID = p.ItemID AND b.IsActive = 1
         LEFT JOIN Items c ON c.ItemID = b.ComponentItemID
WHERE t.TypeCode = 'FG'
GROUP BY p.ItemID, p.ItemCode, p.ItemName, p.ListPrice
ORDER BY p.ItemCode
----

[[FUTON_DBO_I_07]]
=== FUTON_DBO_I_07: the BOM links that break the planning assumptions

The exercises on the bill of materials assume an active link has a positive quantity, a known scrap rate not below 0, the component's own unit, no twin, and a parent that is not a raw material; the schema enforces none of it.
Find the active links that break one of these; the check passes when nothing comes back.

[source,sql]
----
SELECT b.BOMID, p.ItemCode AS ParentCode, c.ItemCode AS ComponentCode, b.Quantity, b.ScrapRate, bu.UnitCode AS BOMUnit, cu.UnitCode AS StockUnit
FROM BillOfMaterials b
         JOIN Items p ON p.ItemID = b.ParentItemID
         JOIN ItemType pt ON pt.ItemTypeID = p.ItemTypeID
         JOIN Items c ON c.ItemID = b.ComponentItemID
         JOIN UnitOfMeasure bu ON bu.UnitID = b.UnitID
         JOIN UnitOfMeasure cu ON cu.UnitID = c.UnitID
WHERE b.IsActive = 1
  AND (b.Quantity <= 0
    OR b.ScrapRate IS NULL
    OR b.ScrapRate < 0
    OR b.UnitID <> c.UnitID
    OR pt.TypeCode = 'RAW'
    OR EXISTS (SELECT 1
               FROM BillOfMaterials other
               WHERE other.ParentItemID = b.ParentItemID
                 AND other.ComponentItemID = b.ComponentItemID
                 AND other.IsActive = 1
                 AND other.BOMID <> b.BOMID))
ORDER BY p.ItemCode, c.ItemCode, b.BOMID
----

[[FUTON_DBO_A_01]]
=== FUTON_DBO_A_01: the raw materials ten futons need, through every level

The raw materials, `RAW`, ten FG-FUT-003 futons need through every active level of the bill of materials, each level's scrap included, and how much of each is available across the warehouses, `0` where none is stocked.

[source,sql]
----
WITH Explosion AS (SELECT b.ComponentItemID, CAST(10 * b.Quantity * (1 + b.ScrapRate / 100) AS DECIMAL(28, 8)) AS Quantity
                   FROM BillOfMaterials b
                            JOIN Items p ON p.ItemID = b.ParentItemID
                   WHERE p.ItemCode = 'FG-FUT-003'
                     AND b.IsActive = 1
                   UNION ALL
                   SELECT b.ComponentItemID, CAST(e.Quantity * b.Quantity * (1 + b.ScrapRate / 100) AS DECIMAL(28, 8))
                   FROM Explosion e
                            JOIN BillOfMaterials b ON b.ParentItemID = e.ComponentItemID
                   WHERE b.IsActive = 1)
SELECT i.ItemCode,
       i.ItemName,
       CAST(SUM(e.Quantity) AS DECIMAL(18, 4))                                          AS Quantity,
       u.UnitCode,
       COALESCE((SELECT SUM(v.QuantityAvailable) FROM Inventory v WHERE v.ItemID = i.ItemID), 0) AS Available
FROM Explosion e
         JOIN Items i ON i.ItemID = e.ComponentItemID
         JOIN ItemType t ON t.ItemTypeID = i.ItemTypeID
         JOIN UnitOfMeasure u ON u.UnitID = i.UnitID
WHERE t.TypeCode = 'RAW'
GROUP BY i.ItemID, i.ItemCode, i.ItemName, u.UnitCode
ORDER BY i.ItemCode
OPTION (MAXRECURSION 0)
----

[[FUTON_DBO_A_02]]
=== FUTON_DBO_A_02: the finished goods which use a raw material, at any level

The finished goods which use RM-FILL-001, at any level, a row per path, with the quantity along the path.

[source,sql]
----
WITH WhereUsed AS (SELECT b.ParentItemID,
                          CAST(b.Quantity AS DECIMAL(18, 4)) AS Quantity,
                          1 AS Level,
                          CAST(c.ItemCode + ' used in ' + p.ItemCode AS NVARCHAR(MAX)) AS UsagePath
                   FROM BillOfMaterials b
                            JOIN Items c ON c.ItemID = b.ComponentItemID
                            JOIN Items p ON p.ItemID = b.ParentItemID
                   WHERE c.ItemCode = 'RM-FILL-001'
                     AND b.IsActive = 1
                   UNION ALL
                   SELECT b.ParentItemID,
                          CAST(w.Quantity * b.Quantity AS DECIMAL(18, 4)),
                          w.Level + 1,
                          CAST(w.UsagePath + ' > ' + p.ItemCode AS NVARCHAR(MAX))
                   FROM WhereUsed w
                            JOIN BillOfMaterials b ON b.ComponentItemID = w.ParentItemID
                            JOIN Items p ON p.ItemID = b.ParentItemID
                   WHERE b.IsActive = 1)
SELECT i.ItemCode, w.Level, w.Quantity, w.UsagePath
FROM WhereUsed w
         JOIN Items i ON i.ItemID = w.ParentItemID
         JOIN ItemType t ON t.ItemTypeID = i.ItemTypeID
WHERE t.TypeCode = 'FG'
ORDER BY i.ItemCode, w.UsagePath
;
----

[[FUTON_DBO_A_05]]
=== FUTON_DBO_A_05: the items in a cycle of the bill of materials

The recursive exercises assume no item is, through any number of levels, a component of itself; the schema stops only the direct case.
Find the items in a cycle of active links; the check passes when nothing comes back.
Each path carries the items it has passed, and stops when it meets one again.

[source,sql]
----
WITH Walk AS (SELECT b.ParentItemID AS StartItemID,
                     b.ComponentItemID AS CurrentItemID,
                     CAST('/' + CAST(b.ParentItemID AS VARCHAR(11)) + '/' + CAST(b.ComponentItemID AS VARCHAR(11)) + '/' AS VARCHAR(MAX)) AS ItemPath,
                     0 AS IsCycle
              FROM BillOfMaterials b
              WHERE b.IsActive = 1
              UNION ALL
              SELECT w.StartItemID,
                     b.ComponentItemID,
                     CAST(w.ItemPath + CAST(b.ComponentItemID AS VARCHAR(11)) + '/' AS VARCHAR(MAX)),
                     CASE WHEN CHARINDEX('/' + CAST(b.ComponentItemID AS VARCHAR(11)) + '/', w.ItemPath) > 0 THEN 1 ELSE 0 END
              FROM Walk w
                       JOIN BillOfMaterials b ON b.ParentItemID = w.CurrentItemID
              WHERE b.IsActive = 1
                AND w.IsCycle = 0)
SELECT DISTINCT i.ItemCode, i.ItemName
FROM Walk w
         JOIN Items i ON i.ItemID = w.StartItemID
WHERE w.IsCycle = 1
  AND w.CurrentItemID = w.StartItemID
ORDER BY i.ItemCode
OPTION (MAXRECURSION 0)
----

[[FUTON_DBO_A_03]]
=== FUTON_DBO_A_03: how many of each futon the components in stock can build

How many of each finished futon the components available in WH-MAIN can build: for each direct component, how many times its quantity is available, none where WH-MAIN does not stock it, and the smallest of those; scrap is not counted.
A futon without an active bill of materials shows NULL.

[source,sql]
----
SELECT p.ItemCode,
       p.ItemName,
       MIN(FLOOR(CASE WHEN v.QuantityAvailable > 0 THEN v.QuantityAvailable ELSE 0 END / b.Quantity)) AS Buildable
FROM Items p
         JOIN ItemType t ON t.ItemTypeID = p.ItemTypeID
         LEFT JOIN BillOfMaterials b ON b.ParentItemID = p.ItemID AND b.IsActive = 1
         LEFT JOIN Inventory v ON v.ItemID = b.ComponentItemID
    AND v.WarehouseID = (SELECT w.WarehouseID FROM Warehouse w WHERE w.WarehouseCode = 'WH-MAIN')
WHERE t.TypeCode = 'FG'
GROUP BY p.ItemID, p.ItemCode, p.ItemName
ORDER BY Buildable DESC, p.ItemCode
----

[[FUTON_DBO_A_06]]
=== FUTON_DBO_A_06: the last movement of each item in the main warehouse

For each item in WH-MAIN, its last inventory transaction: the type, the quantity, what it refers to, and when.
`ROW_NUMBER` over each item, the latest first, keeps one row; `TransactionID` breaks a tie, and a transaction with no date comes last.

[source,sql]
----
WITH Ranked AS (SELECT t.ItemID,
                       t.TransactionTypeID,
                       t.Quantity,
                       t.ReferenceType,
                       t.ReferenceNumber,
                       t.TransactionDate,
                       ROW_NUMBER() OVER (PARTITION BY t.ItemID ORDER BY t.TransactionDate DESC, t.TransactionID DESC) AS Rn
                FROM InventoryTransaction t
                         JOIN Warehouse w ON w.WarehouseID = t.WarehouseID
                WHERE w.WarehouseCode = 'WH-MAIN')
SELECT i.ItemCode, i.ItemName, tt.TypeCode, r.Quantity, r.ReferenceType, r.ReferenceNumber, r.TransactionDate
FROM Ranked r
         JOIN Items i ON i.ItemID = r.ItemID
         JOIN TransactionType tt ON tt.TransactionTypeID = r.TransactionTypeID
WHERE r.Rn = 1
ORDER BY i.ItemCode
----
