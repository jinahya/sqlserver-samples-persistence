[[xml-schemas]]
== XML schemas

AdventureWorks' typed `xml` columns are each the class which `io.github.jinahya:sqlserver-xml-schema-binding-*`
binds their schema collection's schemas to, through a `JaxbAttributeConverter` of `jinahya-persistence-more`;
`README.md` lists them, with the collections and the artifacts. `dbo.DatabaseLog.XmlEvent`, an `EVENTDATA()`
document, is an `EventInstance`. `Production.Illustration.Diagram` is untyped XAML, which no artifact binds, and
stays a `String`. Neither FutonManufacturing nor WideWorldImporters has an `xml` column.

[[large-objects]]
== Large objects

No attribute is `@Lob`. A `varbinary(max)` column, `Production.ProductPhoto`'s photos, `Production.Document.Document`
and WideWorldImporters' `Photo` and `HashedPassword`, is a `byte[]`, and an `nvarchar(max)` one a `String`, which the
driver reads and writes whole.

[[json]]
== JSON

WideWorldImporters keeps JSON in `nvarchar(max)` columns, some checked by `ISJSON`; each is a `String`, and none is
bound. See link:JSON_BINDING.asciidoc[JSON Binding].

[[spatial-and-hierarchy]]
== Spatial and hierarchy

A `geography` column is `-common`'s `Geography`, and a `hierarchyid` one its `Heirarchyid`, each through its
converter, which reads and writes the serialized form of [MS-SSCLRT] itself. Hibernate Spatial is not used: it
reads and writes a `geography` with its latitude and longitude swapped; see `README.md`. A keyless class, which no
converter reaches, takes the column's bytes in its constructor and decodes them.

== Embeddables

The `@Embeddable` id classes of AdventureWorks' seven link tables, `<Entity>Id`, each embedded as
`MappedWithEmbeddedId`'s `id_`, map their key columns; their attributes are among the rows above. The
`@IdClass` id classes map no column. See link:COMPOSITE_PK.asciidoc[Composite Primary Keys].
